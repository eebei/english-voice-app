# 意図分類 正解セット — Yuji記入用（直近4レース・68件）

作成: 2026-09-02 JST / Claude Code

## なぜこれが要るか

8/31実走の失敗を経路別に数えたら、ローカル系14件中8件（57%）が失敗で、**そのうち5件が「聞かれた軸を取り違えた」**ものだった。計算誤りは1件だけ。

つまり今の弱点は計算精度ではなく**質問の理解**である。そこを直すには、まず現行がどれだけ当てているかの実測が要る。

**この正解は人にしか付けられない。** Claude Code や Codex が付けると、自分の計算を自分で採点することになる。

## 記入方法

各行の `軸:` の後ろに記号を1つ書く。複数該当なら `A+C` のように。迷ったら `?` でよい（`?` も情報）。

**システムがどう分類したかは意図的に載せていない。** 見てから付けると引きずられる。

## 軸の一覧

- **A** — GAP（前／後／特定の車との差）
- **B** — 順位
- **C** — 燃料の残量・消費
- **D** — 燃料ウィンドウ（あと何周で開くか）
- **E** — ピット判断を聞く（相談）
- **F** — ピット指示を出す（決定・ボックス）
- **G** — 戦略プラン（A/B・どれ・なぜ）
- **H** — リジョイン／アンダーカット予測
- **I** — 残り周回・残り時間
- **J** — ラップタイム・ベスト
- **K** — ペース比較（自分 vs 他車）
- **L** — 天候・路面
- **M** — 他車の状況（危険・接近・停止車）
- **N** — セッション情報・レース形式
- **O** — 自分の成績履歴（過去のインシデント平均など）
- **P** — 訂正（システムの誤りを正している）
- **Q** — 相槌・独り言・感想（質問ではない）
- **R** — 雑談・目標・レース外の話
- **S** — デブリーフでの回答（Lunaの質問への返答）
- **U** — 機材・ソフトの話（FFB、iRacing再起動、マイク等）
- **V** — いま起きたインシデント／ペナルティへの反応・確認
- **W** — 車の挙動・セットアップの相談
- **T** — 判別不能（STT崩壊）
