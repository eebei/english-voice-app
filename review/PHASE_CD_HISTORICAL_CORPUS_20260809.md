## Build 262候補へ接続する条件

1. セッション開始・変更時に、Practice / Qualifying / Raceのauthorityを一度だけ確定し、全戦略状態を同じSessionNumへ束縛する。
2. clean fuelが成立したら初期Plan A / Plan Bを一度提示する。
3. Plan Aは現在観測できる燃料、残り、同クラス車両、ピットロスから計算する。
4. Plan Bは「次周まで延長可能」が燃料リザーブで成立した場合だけ候補にする。
5. `今入る` と `次周入る` の物理的復帰順位を別スナップショットとして比較する。
6. 他車の将来ピットは推測しない。すでにOnPitRoad、またはピット結果を観測した車両だけをピットサイクル条件へ入れる。
7. 条件が未成立なら、Lunaは確定順位を言わず、次のS/Fで再評価する状態を保持する。
8. 再評価の発火、更新発話、実際のpit entry、pit exit ACK、post-cycle結果を同じdecision idで追跡する。
9. Plan B採用は、燃料安全性と物理的復帰順位の両方がPlan A以上のときに限る。同等ならPlan Aを維持する。
10. 実走後、予測幅内率、順位MAE、燃料誤差、判断変更理由を保存する。
