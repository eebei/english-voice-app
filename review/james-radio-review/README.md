# James radio review — first-listen pack

These ten clips use James's production voice settings:

- Voice: `en-GB-Neural2-B`
- Language: `en-GB`
- Speaking rate: `1.18`
- Pitch: `-2.0`

They are intentionally a small language-and-delivery sample, not a polished
promotional demo. The set mixes immediate radio, engineering judgement and
two-way conversation so James is reviewed as a character rather than only as
a spotter voice.
The reviewer is being asked to challenge the wording and delivery.
The lap-time sample preserves all three millisecond digits used by Build 239.

`review-guide.tsv` gives the situation or driver prompt behind each response.

## Questions for reviewers

1. Would a British race engineer naturally say this?
2. Is it immediately understandable while driving?
3. Is any call too long, too theatrical, or too much like an F1 broadcast?
4. What would you say instead?
5. Does the voice sound credible for James, or does it sound synthetic or
   mismatched to the character?

Honest criticism is the purpose of this review. No positive post or public
endorsement is requested.
